# 🎨 FirstWebExam – Atelje Čuljković

A responsive, single-page website for a fictional painting atelier, **Atelje Čuljković**. Built with plain HTML and CSS as my first web exam project.

The website content is written in **Serbian** (`lang="sr"`).

---

## ✨ Features

- **Fixed navigation bar** with animated underline links
- **Hero section** with a full-screen background image and a call-to-action button
- **About section** – two-column layout (text + image) that stacks on small screens
- **Gallery** – responsive CSS Grid with hover zoom and a sliding title overlay
- **Services & price list** – styled table with zebra rows and hover highlight
- **Contact form** – name, email, phone, service selector and message, with built-in HTML validation
- **Footer** – address, contact info, quick links and social links
- **Responsive layout** – breakpoints at 768px and 480px

## 🛠️ Technologies

| Technology | Used for |
|------------|----------|

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/andrija-culjkovic/FirstWebExam.git
   ```
2. Open the project folder:
   ```bash
   cd FirstWebExam
   ```
3. Open `index.html` in your browser (or use the *Live Server* extension in VS Code).

No build tools or dependencies are required.
